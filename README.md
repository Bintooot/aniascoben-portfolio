## ✨ Highlights & Features

- **⚡ Sleek Hero Section**: Includes an availability badge, dynamic CTA buttons (View Projects, Download Resume), and social link shortcuts.
- **🧭 Responsive Navigation & ScrollSpy**: Desktop navigation bar with active section tracking, plus an accessible mobile drawer overlay.
- **🧑‍💻 Comprehensive About Me**: Highlights key engineering metrics (2+ years experience, 7+ projects, functional ERP knowledge, 20+ tools), educational background, location, and social chips.
- **🏢 Enterprise ERP Knowledge**: Functional knowledge in **SAP Business One**, **ERPNext**, business process mapping, inventory lifecycles, and sales/procurement workflows.
- **💼 Capability & Services Grid**: 6 modern cards covering Frontend Web Development, ERP Systems & Enterprise Workflows, UI/UX Implementation, API Integration, Full-Stack Foundations, and Workflow Automation.
- **🧰 Interactive Skills Filter**: Filterable tabs (All, Frontend, ERP & Enterprise, Backend, Database, Tools & Design) with live item counters and smooth layout animations.
- **🚀 Project Showcase (7 Projects Chronologically)**:
  - **IoT Incubator Controller** (Oct 2024 - Nov 2024) – Mobile application for incubator hardware automation.
  - **Request Management System (RMS)** (Nov 2024 - Feb 2025) – Municipal livestock distribution and ERP-style approval system.
  - **Portfolio v.1** (May 2025 - June 2025) – First iteration of developer portfolio.
  - **Velienne** (May 2025 - June 2025) – Visually engaging restaurant landing page with booking UI.
  - **DevFinder** (June 2025) – GitHub developer profile search engine utilizing GitHub REST API.
  - **IT Hub** (2026) – Modern responsive web application showcasing IT services and portfolios.
  - **SpaceSync** (2026) – Workspace and room reservation platform with real-time scheduling.
- **📬 Interactive Contact Section**:
  - One-click **"Copy Email"** with instant clipboard feedback.
  - Direct links to Email, Phone / WhatsApp, LinkedIn, Messenger, and GitHub.
  - Interactive Contact Form with automated pre-filled email draft.
- **🔝 Floating Scroll-to-Top Button**: Smoothly returns to top when scrolling down.
- **🎨 Modern Dark Aesthetic**: Purple glowing accents (`#8e2de2`, `#4a00e0`), glassmorphic cards, custom scrollbar, and clean typography.
- **📱 Zero Horizontal Overflow**: 100% responsive without horizontal scrollbars across all screen sizes.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Bintooot/aniascoben-portfolio.git

# Navigate into project folder
cd portfolio-v2

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Linting

```bash
# Build production bundle to /dist
npm run build

# Run ESLint validation
npm run lint

# Preview production build locally
npm run preview
```
